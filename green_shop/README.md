# Зелёный дом — онлайн-магазин комнатных растений

Учебный фронтенд-проект: витрина магазина комнатных растений с каталогом,
карточкой товара, личным кабинетом и корзиной. Только HTML5 и CSS3,
без JavaScript и сборки. Bootstrap 5 подключается через CDN и используется
для сеток и элементов форм.

## Страницы

| Файл | Назначение |
|------|------------|
| `index.html` | Главная: hero, преимущества, хиты продаж, блок «О нас», контакты и форма обратной связи |
| `catalog.html` | Каталог: фильтры, сетка растений, таблица сравнения условий содержания |
| `product.html` | Карточка товара: галерея, характеристики, описание, отзывы, похожие растения |
| `account.html` | Личный кабинет: профиль, история заказов, бонусы, настройки |
| `cart.html` | Корзина: список товаров, итоги, промокод, оформление заказа, доставка, FAQ |

## Как открыть

Откройте `index.html` в корне репозитория — сайт статический. Для корректной
загрузки Bootstrap нужен интернет; без него вся вёрстка и локальные стили
продолжают работать.

## Технологии и приёмы

- **Семантика:** `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`,
  `table`, `details/summary`, `address`.
- **Flexbox:** шапка, преимущества, блок «О нас», ценности, контакты, карточки
  отзывов, колонки корзины и формы оформления заказа.
- **CSS Grid:** сетка товаров, галерея миниатюр, футер, турнирная таблица.
- **Таблицы:** сравнение растений, характеристики, история заказов, состав
  корзины, зоны доставки — с «зеброй», подсветкой строки и адаптивным скроллом.
- **Bootstrap 5:** сетки `row`/`col`, `form-control`, `form-check`, `form-select`,
  кнопки; внешний вид переопределён под зелёную тему в `style.css`.
- **Доступность:** skip-link, `aria-*`, `scope` у таблиц, подписи к полям,
  видимый фокус, `prefers-reduced-motion`, поддержка `:focus-visible`.
- **Адаптивность:** мобильная шапка, карточки корзины вместо таблицы на узких
  экранах, перестроение колонок и галереи.

## Соответствие учебным работам

| Работа | Где применена |
|--------|---------------|
| Форматирование текста | заголовки, абзацы, `strong`, `em` на главной |
| Списки, ссылки, изображения | каталог, корзина (`dl`), личный кабинет, карточка товара |
| Таблицы | сравнение в каталоге, характеристики товара, заказы, корзина, доставка |
| Блочная вёрстка | структура всех пяти страниц |
| Flexbox | шапка, преимущества, ценности, карточки, корзина, форма заказа |
| Grid | каталог, хиты продаж, галерея, футер |
| Одностраничник | главная с якорями `#about` и `#contacts` |
| Bootstrap | форма обратной связи, оформление заказа, формы кабинета, кнопки |

## Примечания

- Формы и кнопки «В корзину» — демонстрационные: backend и JavaScript не подключены.
- Фотографии растений используются как локальные плейсхолдеры из папки `img/`.
- Единый дизайн-код: скругления 16–24 px, мягкие тени, зелёная палитра,
  заголовки с засечками и основной текст без засечек.
